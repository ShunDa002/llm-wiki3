# Markdown Retrieval for a Small Wiki

> [!warning] Synthetic near-duplicate source
> This file intentionally restates another test article using slightly different wording.

## Summary

For a Wiki with fewer than roughly 100 pages, begin by testing a curated index, internal links, filenames, and full-text search. Add semantic retrieval only after a benchmark demonstrates that the simpler methods repeatedly miss relevant pages.

Markdown files remain authoritative. Any search index should be treated as derived infrastructure that can be rebuilt.
